# GSA200 模拟数据上位机

这是与 STM32 工程分离的 Windows 串口上位机，默认使用 `921600 / 8N1`，向 GSA200 接收端发送 32 字节模拟数据帧。程序只位于 `host_tool` 目录，不参与 PlatformIO/STM32 构建。

## 协议实现

| 字节 | 内容 |
| --- | --- |
| 1-2 | `AA 55` 帧头 |
| 3 | 序号/格式号 `0x01` |
| 4 | 帧长 `0x20` |
| 5-16 | 3 个 `float` 陀螺仪，单位 °/s |
| 17-28 | 3 个 `float` 加速度，单位 g |
| 29-30 | 温度 `int16`，实际值 = 原始值 / 100 |
| 31 | 采样计数 `1..255` |
| 32 | 前 31 字节累加和的低 8 位 |

STM32 当前 `App/gsa200.c` 按大端解析浮点数和温度，因此界面默认选择“大端（当前固件）”。如果目标设备严格按照图片中的“低字节在前”，可切换“小端（低字节在前）”。

## 运行

```powershell
cd host_tool
python -m pip install -r requirements.txt
python main.py
```

先刷新并选择 COM 口，点击“打开串口”。“固定值”使用输入框中的数据；“正弦模拟”和“随机扰动”会持续生成模拟值。发送频率最高可设为 2000 Hz；单帧按钮可用于先验证接收端。

协议自检：

```powershell
python -m unittest discover -s . -p "test_*.py"
```
